# CV Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-page A4 CV in two variants (`general`, `hornetsecurity`), rendered from typed content and exported to PDF.

**Architecture:** Next.js App Router project whose `src/content/` is the single source of career data. `/cv/[variant]` renders it with a print stylesheet; a Playwright script prints each variant to a committed PDF and fails if a variant overflows one page.

**Tech Stack:** Bun 1.3.14, Node 22, Next.js 16, TypeScript, CSS Modules, `next/font` (Geist + Geist Mono), Playwright 1.63.

**Spec:** `docs/specs/2026-10-03-portfolio-design.md`

## Global Constraints

- One page A4 per variant, real selectable text (no text baked into images).
- CV photo is `viber_image_2026-10-03_15-16-05-227.jpg`, EXIF stripped.
- Credit: ATS 2 claimed fully; ATS 1 "built with one other developer"; Pabau public-safe only.
- Only measured numbers; the headline case-study figures are the ones in the spec's evidence rules.
- No abbreviations in identifiers or rendered strings; `interface` over `type` except unions; named-object arguments.
- No `git commit` without Mihail's explicit go-ahead in the same turn; no attribution trailers.

## Review Focus

- A variant whose content grows past one page must fail the export loudly, not silently print two pages.
- An unknown variant in the URL must 404, never fall back to `general` and ship the wrong CV.
- The PDF must print with the screen's dark mode ignored — dark backgrounds on paper are unreadable.
- Links in the PDF (site, LinkedIn, GitLab, email) must be clickable and point at final URLs.
- Pabau text must stay gated until the public-safe summary arrives — no invented bullets.

### Task 3: PDF export with a one-page guard

**Files:**
- Create: `scripts/export-cv.ts`, `public/cv/mihail-dimoski-general.pdf`, `public/cv/mihail-dimoski-hornetsecurity.pdf`
- Modify: `package.json` (script `cv:export`)

**Interfaces:**
- Consumes: the built site served by `next start` on port 3100, `CV_VARIANTS`.

- [ ] **Step 1: Implement**

```ts
import { chromium } from 'playwright'
import { CV_VARIANTS } from '../src/content/variants'

const A4_HEIGHT_PIXELS = 1123
const PRINT_MARGIN_PIXELS = 91

const browser = await chromium.launch()
const page = await browser.newPage()
await page.emulateMedia({ media: 'print', colorScheme: 'light' })
for (const variant of CV_VARIANTS) {
  await page.goto(`http://localhost:3100/cv/${variant}`, { waitUntil: 'networkidle' })
  const contentHeight = await page.evaluate(() => document.documentElement.scrollHeight)
  if (contentHeight > A4_HEIGHT_PIXELS - PRINT_MARGIN_PIXELS) {
    throw new Error(`${variant} overflows one page: ${contentHeight}px`)
  }
  await page.pdf({ path: `public/cv/mihail-dimoski-${variant}.pdf`, format: 'A4', printBackground: true, preferCSSPageSize: true })
}
await browser.close()
```

- [ ] **Step 2:** Prove the guard: temporarily duplicate the experience list, run, expect the overflow error; revert.

- [ ] **Step 4:** Verify: `pdfinfo` shows `Pages: 1` for both; `pdftotext` output contains the name and every section heading; links are clickable.
